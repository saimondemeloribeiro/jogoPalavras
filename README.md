# Palavra

Jogo diário de dedução de palavras em português brasileiro. O MVP mantém partida e estatísticas no navegador; a resposta do desafio está no cliente e o catálogo é apenas uma amostra editorial.

## Executar

Requer Node.js 20.19+ ou 22.12+.

```sh
npm install
npm run dev
```

## Verificar

```sh
npm test
npm run build
```

O PRD inicial, com decisões provisórias e critérios de aceite, está em `docs/plans/2026-10-20-jogo-de-palavras.md`. Antes de publicação, confirme o fuso do desafio e revise/licencie o vocabulário.
